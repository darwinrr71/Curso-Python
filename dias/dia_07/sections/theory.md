Tuplas

Una tupla es una colección ordenada e inmutable.

point = (10, 20)

Se usa cuando quieres representar un conjunto fijo de valores que no deberían cambiar fácilmente.

Sets

Un set es una colección no ordenada de elementos únicos.

unique_numbers = {1, 2, 3}

Sirve para eliminar duplicados y hacer operaciones de conjunto.

Diccionarios

Un diccionario guarda pares clave-valor.

user = {"name": "Ana", "age": 30}

Es fundamental cuando quieres representar entidades con propiedades.
