Qué es un entorno virtual

Un entorno virtual es un espacio aislado donde un proyecto tiene sus propias dependencias de Python. Esto evita conflictos entre proyectos que necesitan versiones distintas de paquetes.

venv Es la herramienta estándar incluida en Python para crear entornos virtuales. pip Es el gestor de paquetes más usado en Python. requirements.txt Es un archivo de texto donde se listan dependencias necesarias para reproducir un entorno.
