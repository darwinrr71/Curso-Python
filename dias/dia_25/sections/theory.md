Type hints

Permiten indicar qué tipo se espera en variables, parámetros y retornos.

```python
def add(a: int, b: int) -> int:
    return a + b
```

No obligan en tiempo de ejecución por sí solos, pero mejoran claridad, tooling y mantenimiento.

dataclass

Reduce código repetitivo en clases usadas principalmente para almacenar datos.
