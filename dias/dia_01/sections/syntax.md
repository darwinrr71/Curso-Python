Asignación de variables

name = "Carlos"

name es el identificador o nombre de la variable. = es el operador de asignación. "Carlos" es el valor que se asigna.

Mostrar valores con print()

name = "Carlos"
print(name)

Esto imprime el contenido actual de la variable name.

Consultar el tipo con type()

age = 25
print(type(age))

type() devuelve el tipo del valor.
