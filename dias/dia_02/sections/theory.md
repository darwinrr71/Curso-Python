Los programas no solo guardan valores: también los transforman. Para eso necesitas operadores. Python ofrece operadores para sumar, restar, multiplicar, dividir, comparar valores y combinar condiciones.

Operadores aritméticos

+ suma - resta * multiplicación / división con resultado float // división entera % módulo o residuo ** potencia

Operadores de comparación

Devuelven True o False. - == -!= - > - < - >= - <=

Operadores lógicos

and or not

Conversión de tipos

A veces necesitas convertir un valor de un tipo a otro. - int() convierte a entero - float() convierte a decimal - str() convierte a texto - bool() convierte a booleano
