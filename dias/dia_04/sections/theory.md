Los condicionales permiten ejecutar distintos bloques según si una condición es verdadera o falsa.

Python no usa llaves {} para delimitar bloques como C, Java o JavaScript. Usa indentación. Eso significa que los espacios al inicio de línea no son decoración: forman parte de la sintaxis.

Estructura básica

```python
if condition:
    # block
elif another_condition:
    # another block
else:
    # fallback block
```
