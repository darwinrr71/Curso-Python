JSON es un formato de intercambio de datos muy usado en APIs, archivos de configuración y almacenamiento simple. Se parece mucho a objetos de JavaScript, pero no es exactamente lo mismo.

Equivalencias comunes

objeto JSON ↔ diccionario Python array JSON ↔ lista Python string JSON ↔ str number JSON ↔ int o float true / false ↔ True / False null ↔ None
